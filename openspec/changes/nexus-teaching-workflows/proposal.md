# Nexus 教学业务升级

## 目的

在已有 Flask 课程平台中增加可运行的知识回补、同纲不同卷和可信学情周报，保留独立课程数据。新增版本采用 PostgreSQL/pgvector、LangGraph、官方 MCP Python SDK、Redis/RQ 和 Vue 双端。

## 业务约束

- 服务端根据当前数据库用户校验角色和班级；JWT 只存身份，退出时撤销；MCP 每次调用重新认证并检查应用绑定。
- 材料采用不可变版本。索引事务成功后切换活动版本，失败不影响旧版本，历史消息保存原始引用片段及哈希。
- 检索只在本班当前应用材料中进行，全文与向量结果用 RRF 融合；无依据登记候选缺口，教师确认后补充，索引完成且原问题可命中才算回补。
- 应用绑定模板、技能和工具。LangGraph 组织检索、模型、工具及结果回传，最多三次模型请求；上传技能不执行任意代码。
- 作业按人生成参数和标准答案；答案只在服务端保存；开始作答后冻结；单人发卷任务失败不回滚其他人。
- AI 批改采用 Pydantic 校验，核对 Rubric 维度及分数；数值题答案错误时不允许满分。教师复核保留 AI 原分。
- 周报统计由程序计算，模型只写解读；样本不足不推断趋势；学生只能看本班发布版。
- 后台任务保存状态与错误，失败支持教师重试；每个 HTTP 请求和 Agent 调用保留关联审计。

## 验收

采用真实 PostgreSQL 隔离测试、真实 Redis/RQ 与演示数据集成验证、浏览器交互以及隔离 Docker 公网访问验证。测试替身与真实模型验证分别记录，不把 mock 当作真实上游结果。既有服务器网站及容器不得修改或停止。本次依用户要求先部署 IP:8088，HTTPS 留待后续配置。
